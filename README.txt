Folders:
	data - Данные от MNIST для классификации
	Images - Собственные изображения для инференса
	Models - Сохранения моделей во время работы, со следующим обозначением "ARCHITECTURE(number)_b{batch_size}_e{number_epoch}"
    Tensors images - Изображения из "Images" перенесенные и сохраненные на тензорах от PyTorch

Files:
	MLP.py - Полносвязная нейронная сеть для классификации
	СNN.py - Нейронная сеть со сверточными слоями для классфикации
	images_to_tensor - Вспомогательный файл для конвертации изображений в тензоры
	Отчет.docx - Отчет по проделанной работе со всеми мыслями и идеями.
